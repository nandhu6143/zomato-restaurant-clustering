# Zomato Restaurant Clustering

## Project Overview

This project focuses on analyzing Zomato restaurant data and customer reviews to understand restaurant trends and group similar restaurants into meaningful segments.

The project uses Exploratory Data Analysis (EDA), customer review sentiment analysis, feature engineering, and unsupervised machine learning techniques.

## Problem Statement

The main aim of this project is to analyze restaurant information and customer feedback and identify different types of restaurant segments.

These segments can help understand customer preferences, restaurant performance, pricing patterns, and areas where restaurants can improve.

## Dataset

The project uses two datasets:

### 1. Restaurant Metadata
This dataset contains information such as:
- Restaurant Name
- Cost
- Collections
- Cuisines
- Timings

### 2. Restaurant Reviews
This dataset contains:
- Restaurant Name
- Reviewer
- Review
- Rating
- Metadata
- Time
- Pictures

## Machine Learning Models

The following unsupervised learning algorithms were used:

- K-Means Clustering
- Agglomerative Clustering
- Gaussian Mixture Model

The models were compared using clustering evaluation metrics such as:

- Silhouette Score
- Davies-Bouldin Index
- Calinski-Harabasz Score

## Key Analysis

The project analyzes relationships between:

- Restaurant cost and rating
- Review count and rating
- Customer sentiment and rating
- Cuisine and cost
- Restaurant popularity and customer engagement

The clustering results are used to identify groups of restaurants with similar characteristics.

## Business Use

The results can help:

- Understand different restaurant segments
- Improve restaurant recommendations
- Identify customer satisfaction patterns
- Find restaurants that need improvement
- Support targeted promotions
- Understand pricing and cuisine trends
